## Goal

Help teams understand project progress by showing the events and evidence behind it.

## Scope described in the issue

- Add a project timeline that presents relevant delivery evidence in chronological order.
- Link timeline items to their source when available.
- Show source and timestamp clearly.
- Define how missing or delayed evidence is represented.
- Keep the timeline usable on smaller screens and accessible to keyboard users.

## Acceptance criteria

- [ ] Users can see relevant evidence for a project in chronological order.
- [ ] Each item shows provenance and a useful source link when available.
- [ ] Empty, loading, and error states are clear.
- [ ] Users cannot view evidence from another workspace.
- [ ] UI tests or documented review cover the main states.
