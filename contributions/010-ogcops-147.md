## 1. Problem and requirements

The `/templates` gallery search needed to find templates by name, description, and tags, and needed to support URL query and category parameters.

## 2. Implementation

Gallery search now matches names, descriptions, and tags case-insensitively. `?q=` prepopulates and applies a query; `?category=` selects a category; the parameters compose, and unknown categories fall back to All. Result counts and the empty state remain in sync. The page also uses URL state consistently with the editor search.
