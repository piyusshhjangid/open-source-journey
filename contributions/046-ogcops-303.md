## 1. Problem and requirements

Adds the `blog-benchmark` template with up to four scaled comparison bars, formatted values and optional units. Invalid rows are skipped, zero values render empty bars safely, and the chart hides when no rows remain. Long titles, notes and names shrink and truncate. Light backgrounds use readable text and accent colors.

The template is exported from the Blog index and registered in the template registry, with focused tests for scaling, validation, empty states, formatting, long text and light-background contrast.
