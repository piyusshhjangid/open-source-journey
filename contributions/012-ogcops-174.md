## 1. Problem and requirements

The tutorial gallery needed a quiz card template with configurable answers and an optional answer reveal.

## 2. Implementation

Added `tutorial-quiz-card` with a question, category and Quiz pills, four answer choices in a 2-by-2 layout, configurable options and correct answer, optional answer reveal, registry/tutorial-index entries, and support for customizable colors. Light backgrounds use a darkened accent for readable answer letters and reveal text.
